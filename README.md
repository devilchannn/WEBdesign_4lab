# FRAME CINEMA — учебное демо бронирования

## Тема
Кинотеатр: пользователь выбирает сеанс, свободные места на плане зала, видит стоимость и получает учебный билет.

## Стек
- HTML5
- CSS3
- Vanilla JavaScript
- ES Modules
- localStorage

## Функции
- выбор одного из двух сеансов;
- схема зала 4 × 6 (24 места);
- список тех же мест, что и на схеме;
- статусы мест: свободно / выбрано / занято;
- фильтры по ряду, максимальной цене и опция «только свободные»;
- выбор нескольких мест;
- расчёт итоговой стоимости;
- подтверждение учебного билета;
- раздел «Мои брони»;
- отмена билета и освобождение мест;
- сохранение бронирований в localStorage;
- сброс учебного демо;
- адаптивная вёрстка и работа с клавиатуры.

## Как запустить
Так как используются ES-модули, проект лучше открывать через локальный HTTP-сервер или GitHub Pages.

Самый простой способ через VS Code + Live Server или любой локальный сервер.

## Учебное ограничение
Это учебное демо. Реальные билеты, оплата и отправка e-mail не выполняются.
